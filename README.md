# Groq Free STT

Mac의 시스템 소리, 마이크 또는 음성 파일을 전사하는 로컬 앱입니다. 음성은 Groq API로 전송되며 작업과 결과는 Mac에 저장됩니다.

## 준비와 실행

macOS 14.2 이상, Python 3, `make`, Swift 컴파일러와 `codesign`(Xcode 또는 Command Line Tools), `ffmpeg`와 `ffprobe`, Groq API 키가 필요합니다. 시스템 소리와 마이크 녹음에는 각각 macOS 시스템 오디오 권한과 브라우저·macOS 마이크 권한이 필요합니다.

저장소에서 `make setup`을 실행한 뒤 생성된 `.env`에 `GROQ_API_KEY=키`를 입력합니다. 기존 `.env`는 덮어쓰지 않습니다. 그런 다음 `make start`로 서버를 시작합니다.

브라우저에서 <http://127.0.0.1:8765>를 엽니다. 종료하려면 다른 터미널에서 `make stop`을 실행합니다. `PORT`를 변경했다면 시작과 종료에 같은 값을 지정하고, API 키를 변경했다면 서버를 재시작하세요.

## 사용과 데이터

홈에서 시스템 소리, 마이크 또는 음성 파일을 선택합니다. 시스템 소리는 녹음 종료 후 보관된 녹음에서 **전사**를 선택하고, 마이크와 파일은 녹음 또는 업로드 후 전사가 시작됩니다. 한 번에 하나의 전사 작업만 진행할 수 있습니다. 결과는 MD 또는 TXT로 다운로드할 수 있습니다.

전사는 일시 정지, 계속, 정지할 수 있습니다. 일시 정지는 현재 구간이 끝난 뒤 적용되며, 정지하면 부분 전사는 삭제되고 원본은 보관됩니다. 서버 재시작 시 진행 중인 전사는 저장된 구간부터 재개되지만, 사용자가 일시 정지한 작업은 직접 계속해야 합니다.

데이터는 `~/.groq-free-stt/`에 저장되며 앱에서 원본 또는 전체 항목을 삭제할 수 있습니다. 보관된 녹음은 해당 목록에서 삭제합니다. 기존 `~/.lonta/` 데이터는 자동 이관되지 않습니다.

## 제한

- Groq 사용 한도는 로컬 기록을 기준으로 추정하므로 실제 한도와 다를 수 있습니다. 429 응답이 세 번 연속 발생하면 수동으로 계속해야 합니다.
- 중단된 녹음은 보관된 녹음에서 확인하고 전사할 수 있지만, 마지막 구간 유실이나 손상된 녹음의 복구 실패가 발생할 수 있습니다. 정상 종료에는 `make stop`을 사용하세요.
- 시스템 오디오 원본은 장시간 녹음 시 디스크 공간을 많이 사용하며 WAV 크기 제한을 넘으면 복구할 수 없습니다. 권한 거부와 실제 무음은 구별되지 않을 수 있습니다.
- 실기기 마이크 녹음, 권한 거부, 실제 한도 동작 등 일부 사용 흐름은 아직 검증되지 않았습니다.
